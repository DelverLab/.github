# DelverLab brand assets

Every asset comes as SVG (`svg/`) and PNG (`png/`). Text in the SVGs is converted to outlines, so they look the same without the font installed.

## Naming

- **`-light`**: for light backgrounds (dark text)
- **`-dark`**: for dark backgrounds (light text)
- **`-bg`**: includes its own background. Files without `-bg` have a transparent background.

## Files

| Asset | Files | PNG size |
|---|---|---|
| Icon | `delverlab-icon-light`, `-icon-dark`, `-icon-light-bg`, `-icon-dark-bg` | 1024×1024 |
| Wordmark | `delverlab-wordmark-light`, `-wordmark-dark`, `-wordmark-light-bg`, `-wordmark-dark-bg` | 1500×320 |
| Banner | `delverlab-banner-light`, `-banner-dark`, `-banner-light-bg`, `-banner-dark-bg` | 1600×400 |
| Avatar | `delverlab-avatar` (square, dark background) | 1024×1024 |
| App icon | `delverlab-app` (rounded square, dark background) | 1024×1024 |
